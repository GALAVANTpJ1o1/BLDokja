A 4BLD solve has three phases, one per piece type, and each ends with its own parity step when that piece type's target count is odd:

1. **x-centres**, then centre parity if the count is odd;
2. **wings**, then wing parity if the count is odd;
3. **corners**, then corner parity if the count is odd.

The next lessons teach each phase and lesson 8 teaches all three parity steps. This lesson is about the order.

## Centres first

Every phase puts back everything that isn't its own piece type. Setups are undone, and the swap's side effects cancel in pairs. The parity steps are where the order starts to matter.

The wing and corner parity algs undo their leftover, but along the way they're allowed to swap x-centres **of the same colour** with each other. On a cube whose centres are solved that's invisible: a white x-centre swapped with another white x-centre is still white in a white slot. On a cube whose centres aren't solved yet, the same swap moves colours around, and the centre memo you made no longer matches the cube.

So centres come first. After that, wings and corners don't disturb each other, and this site does wings before corners.

Five targets: an odd count, so the phase ends with one more U2, which lesson 5 explains. Every other piece type still has its targets waiting, untouched by the centre phase.

## What about memo?

The order you execute in doesn't force an order to memorise in. Whatever order you choose, keep it the same every solve, so recall never has to guess which list comes next. This site's trainers trace x-centres, then wings, then corners, the same as the solve.
