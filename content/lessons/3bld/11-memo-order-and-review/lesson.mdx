You can trace and you can memorise. This lesson is about putting them together so that the memo you need is still there when you need it.

## Solve order on this path

Old Pochmann on this path solves in this order:

1. **Edges**, target by target.
2. **Parity**, if the number of targets is odd (lesson 14 explains why).
3. **Corners**, target by target.

That order is fixed by the method, because the parity step only works between the two.

## Memorise the first thing you'll solve last

Memory fades fastest right after you stop rehearsing. So a good default is:

- memorise **corners first**;
- memorise **edges last**, so they're the freshest thing in your head;
- put the blindfold on and start with **edges**, while they're still fresh.

Edges usually have more targets than corners too, so they're the ones that most need to be fresh. If you find your corners fading by the time you reach them, try the opposite order for a week and compare. There's no single right answer, only the order you can repeat.

## Review before the blindfold

Before you put the blindfold on, walk your routes once more, from the first image to the last, and check each one gives the letters you traced. It takes seconds and catches most mistakes while you can still look.

Also note one fact that isn't a pair: **is the number of targets odd?** On this scramble both counts are odd, so this solve needs the parity step. Tie it to the last image, or just say "parity" to yourself at the end of the review.

<Note>At first, write the memo on paper and check your recall against it after the solve. You'll learn quickly which pairs your memory drops, and those are the ones to give better images.</Note>
